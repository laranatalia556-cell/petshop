# 🐾 Pet Feliz - Projeto Petshop | Fase 2

Projeto acadêmico desenvolvido para a disciplina de Fundamentos de Sistemas Web.

O Pet Feliz é um site fictício de petshop desenvolvido utilizando HTML, CSS, Bootstrap e JavaScript.

## 📌 Funcionalidades

O site possui:

- Página inicial com apresentação do Pet Feliz;
- Carrossel de imagens utilizando Bootstrap;
- Página de produtos divididos nas categorias Alimentação, Brinquedos e Acessórios;
- Página com os serviços oferecidos pelo petshop;
- Cadastro de cliente;
- Cadastro do pet;
- Escolha entre os serviços de Banho e Tosa;
- Escolha entre tele-busca ou levar o pet até o estabelecimento;
- Seleção de data e horário para o atendimento;
- Validação dos campos obrigatórios do formulário;
- Bloqueio de datas anteriores ao dia atual utilizando JavaScript;
- Confirmação do agendamento através de JavaScript;
- Página com informações de contato e horário de atendimento.

## ♿ Acessibilidade

O projeto possui recursos básicos de acessibilidade, como:

- Textos alternativos (`alt`) nas imagens;
- Identificação dos campos dos formulários;
- Link para pular diretamente para o conteúdo principal;
- Destaque visual ao navegar pelos elementos utilizando o teclado.

## 🎨 Bootstrap e CSS

O Bootstrap foi utilizado para melhorar a organização e a aparência das páginas, incluindo:

- Carrossel de imagens;
- Cards para produtos e serviços;
- Botões;
- Organização responsiva dos conteúdos.

Também foi utilizado um arquivo CSS personalizado para manter a identidade visual do Pet Feliz.

## ⚙️ JavaScript

O JavaScript foi utilizado na página de cadastro e agendamento para:

- Identificar automaticamente a data atual;
- Impedir a escolha de datas anteriores;
- Capturar os dados principais do agendamento;
- Exibir uma mensagem de confirmação após o envio do formulário.

## 📖 Como utilizar

Utilize o menu superior para navegar entre as páginas do site.

Na página **Produtos**, é possível visualizar os produtos disponíveis e seus respectivos valores.

Na página **Serviços**, são apresentados os serviços oferecidos pelo Pet Feliz. Os serviços de Banho e Tosa possuem opção de agendamento.

Na página **Cadastro e Agendamento**, preencha os dados do cliente e do pet, escolha o serviço desejado, a forma de atendimento, a data e o horário. Depois, confirme as informações e clique em **Agendar serviço**.

Ao finalizar, o sistema exibirá uma mensagem confirmando o agendamento.
